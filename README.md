# searching-algorithms-java
Implementations of common searching algorithms in Java with explanations.

---

## 🔎 Searching Algorithms Covered

- Linear Search  
- Binary Search
- Jump Search  
- Interpolation Search  
- Exponential Search  
- Fibonacci Search 

---

## 📊 Comparison Table

| Algorithm            | Best Case | Average Case | Worst Case | Space Complexity | Notes |
|----------------------|-----------|--------------|------------|------------------|-------|
| Linear Search        | O(1)      | O(n/2)       | O(n)       | O(1)             | Works on unsorted arrays |
| Binary Search        | O(1)      | O(log n)     | O(log n)   | O(1)             | Requires sorted array |
| Jump Search          | O(1)      | O(√n)        | O(√n)      | O(1)             | Good for sorted arrays |
| Interpolation Search | O(1)      | O(log log n) | O(n)       | O(1)             | Best for uniformly distributed data |
| Exponential Search   | O(1)      | O(log n)     | O(log n)   | O(1)             | Useful for unbounded arrays |
| Fibonacci Search     | O(1)      | O(log n)     | O(log n)   | O(1)             | Similar to binary search, uses Fibonacci numbers |
